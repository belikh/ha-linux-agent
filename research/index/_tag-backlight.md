# Tag: backlight

- [[backlight-support-the-linux-kernel-documentation]] — Backlight support — The Linux Kernel documentation — Kernel backlight documentation (current for 7.3.0-rc1). Backlight sysfs attributes: brightness (R/W — the REQUESTED level), actual_brightness (RO — the level actually used by HW), max_brightness (RO). Interface at /sys/class/backlight/<backlight>/brightness and /sys/class/backlight/<backlight>/bl_power (power mode: 0 full on, 4 full off). Drivers must implement get_brightness() if HW doesn't support every brightness value, so actual_brightness is the readback truth. uevents are emitted on actual_brightness when backlight changes; hotkey/platform brightness changes require the driver to call backlight_force_update() to re-sync userspace (BACKLIGHT_UPDATE_HOTKEY vs BACKLIGHT_UPDATE_SYSFS reasons). backlight_type enum: RAW (hardware registers), PLATFORM (platform-specific interface), FIRMWARE (standard firmware interface) — userspace can make policy decisions based on type. For a fleet agent controlling kiosk brightness: write brightness for control, read actual_brightness for state truth (a write may be clamped or ignored by HW), max_brightness for the scale, and type for preferring firmware/native interfaces.
