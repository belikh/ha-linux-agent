- [[mqtt-home-assistant]] — MQTT - Home Assistant — Official Home Assistant MQTT integration reference. Load-bearing details for any agent implementing MQTT discovery: (1) HA publishes birth message 'online' to homeassistant/status on MQTT integration start, LWT 'offline' on shutdown/crash; devices should subscribe and re-send discovery payloads on birth, with random delay recommended to avoid broker IO spikes. (2) On HA restart all discovered MQTT items WITH unique_id become unavailable until a new discovery message; items without unique_id are not added at startup. (3) Two discovery-restoration approaches: birth-triggered rediscovery vs retained discovery messages — retained messages can create 'ghost entities' and HA supports message_expiry_interval (MQTT 5) to bound retention. (4) Availability: per-entity availability_topic/availability list with payload_available ('online' default) and payload_not_available ('offline'), availability_mode all/any/latest; broker publishes LWT when client loses connection. (5) last_reported attribute only updates when force_update is set. (6) MQTT subentries (new) allow device context + entities per subentry. (7) ActiveMQ and RabbitMQ MQTT plugin explicitly unsupported — retention broken. `evergreen`
