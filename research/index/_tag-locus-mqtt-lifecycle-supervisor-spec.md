EventLoop holds: mqtt_options (pub, user-editable between connections), state: MqttState (pub), a flume bounded request channel (requests_tx/requests_rx, capacity = Client::new cap), and 'pub pending: VecDeque' — pending packets from last session. poll(): when network is None it (re)connects with timeout, then 'if !connack.session_present { self.pending.clear(); }' — clean sessions drop pending; persistent sessions resume them. select() dispatches 'Self::next_request(&mut self.pending, &self.requests_rx, ...)' which pops pending first (with pending_throttle sleep) else rx.recv_async() — so requests enqueued via client.subscribe() BEFORE first connect sit in the bounded flume channel and are drained after CONNACK. clean() moves state's unacked publishes + pending PubRels into eventloop.pending, drains the channel too, retains everything EXCEPT Request::PubAck (dropped to avoid confusing the broker with unexpected acks), and nulls network/keepalive.
